【快速启动】

1️⃣  启动前端（新终端）
   双击运行：启动前端.bat
   或手动：
   cd apps/ui
   npm install      (首次运行)
   npm run dev

   → 访问 http://localhost:3000

2️⃣  启动后端（新终端）
   双击运行：启动后端.bat
   或手动：
   .\.venv\Scripts\Activate.ps1
   uvicorn apps.api.main:app --reload --port 8000

   → API: http://localhost:8000
   → 文档: http://localhost:8000/docs

【常见问题】

Q: npm install 失败？
A: rm -rf node_modules package-lock.json
   npm cache clean --force
   npm install

Q: 端口被占用？
A: 修改 apps/ui/vite.config.ts 中的 port

Q: OpenAI API 调用失败？
A: 检查 .env 中的 GPT_API_KEY

Q: PDF 导出失败？
A: pip install playwright
   python -m playwright install chromium

【首次配置】

1. 安装后端依赖：
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt

2. 配置环境变量：
   Copy-Item .env.example .env
   # 编辑 .env，填入 GPT_API_KEY

3. 安装前端依赖：
   cd apps/ui
   npm install
   cd ..\..

4. 启动服务（见上方）
